---
description: How to trigger the User-Generated Content (UGC) share workflow for talent
---

1. Ensure the user has completed their profile and uploaded a "Proof Clip".
2. Generate the shareable video metadata (15s clip + branding).
3. Provide the user with their unique referral link.
4. Prompt the user: "Share your ShapaCV on TikTok to earn your Social Badge!"
5. Track sign-ups via the referral link.
// turbo
6. Run `npm run verify-referrals` to check credits (if CLI tool exists).
